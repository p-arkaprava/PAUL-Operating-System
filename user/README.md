# user — User-space programs (Phase 5–6)

Programs that run in ring 3 and talk to the kernel only through system calls.

**Will contain:**
- `lib/` — tiny libc: syscall wrappers, `printf`, string functions
- `shell/` — the Paul OS shell
- `programs/` — `hello`, `ls`, `cat`, `echo`, …

**Book:** Ch 2.1–2.3 (OS services, user interface, system calls)
